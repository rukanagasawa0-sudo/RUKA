# RUKA カードゲームシミュレーター

身内で遊ぶための、オンライン対戦できる**汎用トレーディングカードゲーム・エンジン**です。
2人がそれぞれのスマホ/PCのブラウザから同じ「ルーム」に入り、山札・手札・フィールド・トラッシュ・
パートナー枠・事件カード枠を使って対戦できます。フェイズ（オート／メイン／エンド）とターンの
管理、ライフなどのカウンター、簡易チャットも入っています。

## ⚠️ 著作権についての大事な注意

このリポジトリには**特定の市販カードゲームのカード名・効果テキスト・イラストは一切含まれていません**。
同梱している `cards/sample-cards.json` は動作確認用のダミーデータです。

実際に遊ぶ際は、**自分たちで用意したカードデータ（JSON）と画像**を読み込んで使ってください。
既存の市販カードゲームのカード情報をそのまま入力・アップロードして不特定多数に公開したり、
販売目的で使ったりすることはできません。あくまで身内内輪で、自分たちが所有するカードを
digital化して遊ぶ用途を想定しています。取り扱いは自己責任でお願いします。

## 遊び方の流れ

1. サーバーを起動する（下記セットアップ参照）
2. 1人目がブラウザで開いて「ルームを作る」→ ルームコード（例: `AB12CD`）が発行される
3. そのコードを相手に伝え、相手は「参加する」から同じコードで入室
4. どちらか（ホスト役）が①でカードデータ（JSON）を読み込む
   - とりあえず試すだけなら「サンプルデータを読み込む」でOK
   - 自分たちのカードを使う場合は、後述のJSON形式でファイルを作って読み込む
5. 画像を使いたい場合は②で画像をアップロードし、発行されたURLをJSONの `image` に入れる
6. ③で各自40枚のメインデッキ＋パートナーカード＋事件カードを選ぶ→「デッキ確定」
7. 両者確定したら④「対戦開始」
8. 盤面でカードをクリックすると、移動先（手札／フィールド／トラッシュ／パートナー枠／事件枠／山札の上・下）
   を選べるメニューが出ます。ライフなどのカウンターは＋／－ボタンで増減できます

カードの効果そのもの（能力の自動処理）はエンジン側では判定しません。実物のカードゲームを
オンラインの卓上で再現するイメージで、効果の適用はプレイヤー同士の申告（自己申告）で行ってください。

## セットアップ（ローカルで動かす）

Node.js 18以上が必要です。

```bash
npm install
npm start
```

`http://localhost:3000` にブラウザでアクセスします。

## 友達とオンラインで対戦するには

このアプリは1台のサーバーに全員がブラウザからアクセスする形なので、誰か1人（ホスト役）が
サーバーを立てて、他の人がそのURLにアクセスする必要があります。主な方法：

- **無料ホスティングにデプロイ**（おすすめ・一番手軽）: Render / Railway / Fly.io などのNode.js対応
  無料プランにこのリポジトリをデプロイすると、常時アクセスできるURLが発行されます
- **一時的な公開トンネル**: ホスト役のPCで `npm start` した状態で、`ngrok http 3000` や
  Cloudflare Tunnel (`cloudflared tunnel --url http://localhost:3000`) を使うと一時的な公開URLが発行できます
- **同じWi-Fi/LAN内**: 同じ場所に集まっている場合はホストのPCのローカルIP（例: `http://192.168.x.x:3000`）
  に他の端末からアクセスするだけでOKです

## カードデータのJSON形式

```json
{
  "settings": { "mainDeckSize": 40, "openingHand": 5, "startingLife": 8 },
  "cards": [
    {
      "id": "chr-01",
      "type": "character",
      "name": "カード名",
      "text": "効果テキスト（任意）",
      "image": "https://example.com/img.png または /uploads/ABCXYZ/xxxx.png（任意）"
    }
  ]
}
```

- `type` は自由な文字列ですが、デッキ構築画面では `partner` / `case` タイプだけが
  パートナー枠・事件枠の選択肢として扱われ、それ以外はメインデッキ用の候補になります
- `image` を省略すると、カード名だけのシンプルな見た目で表示されます
- 画像はアプリの「②カード画像を追加」からアップロードすると `/uploads/...` のURLが発行されるので、
  それを `image` に貼り付けてください（アップロード画像はサーバーのローカルに保存され、
  Gitリポジトリにはコミットされません）

## 技術構成 / 制限事項

- Node.js + Express + Socket.IO（リアルタイム同期）、フロントは素のHTML/CSS/JS
- 対戦データはすべてメモリ上で管理しており、**サーバーを再起動すると消えます**（DBなし・認証なし、
  身内の一時利用を想定したシンプル構成です）
- 1ルームにつき2人対戦を想定しています
- カード効果の自動判定は行いません（ゾーン移動・カウンター管理・フェイズ/ターン進行のみ）

## ディレクトリ構成

```
server/index.js        サーバー本体（ルーム管理・対戦状態・画像アップロード）
public/                 フロントエンド（index.html / style.css / app.js）
cards/sample-cards.json 動作確認用のダミーカードデータ
```
