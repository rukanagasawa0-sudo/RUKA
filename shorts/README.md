## お店の名前・告知文

`config.py` の `SHOP_NAME`（トレカラフテル）、`SHOP_INFO`（秋葉原の店舗＆通販URL）、告知文を書き換えて再生成すると全動画に反映されます。

## 作り直し・新しい動画の追加

```bash
pip install pillow numpy          # ffmpeg も必要
python3 shorts/make.py            # 全部作る
python3 shorts/make.py v3         # 1本だけ
python3 shorts/make.py v3 --preview   # 静止画8枚だけ書き出して確認（速い）
```

- 字幕と画面中央の文字・画像が重なっていないかは `python3 shorts/tools/check_overlap.py` で全フレーム検査できます。
- 台本は `scripts/v*.py`。`s.scene(描画関数, (話者, 字幕, 読み, 効果音), ...)` を並べるだけです。
  字幕の `*囲み*` は赤字で強調されます。読み間違える単語は3番目の「読み」にひらがなで書きます。
- 話者は `engine/render.py` の `CHARS`（VOICEVOX のスタイルID）から選べます。
- 音声は VOICEVOX ENGINE の API で作ります。手元の PC で VOICEVOX を起動していればそれ
  (`http://127.0.0.1:50021`) を優先し、なければ公開エンジンを使います。
- BGM・効果音はプログラムで合成しているので著作権の心配はありません。
- 公式画像の取得: `python3 shorts/tools/cardlist.py <シリーズID> [検索語]` でカード番号を調べ、
  `python3 shorts/tools/getcard.py OP18-001 ...` で `assets/official/cards/` に保存します。
- フォント: Noto Sans JP / M PLUS Rounded 1c / Dela Gothic One（いずれも SIL Open Font License）。
